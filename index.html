      Page Goblin

      An EPUB reader that runs in your browser. The goblin keeps your books, positions and notes on this device, and it shares them with no one. With sync on, it also keeps a copy on your own sync server.

      Sync

      Sync copies your books, reading positions, bookmarks and highlights between your devices. It uses a server in your own Cloudflare account. With sync off, all data stays on this device.

      How to make your sync server

      A device that syncs shows its code here, in Sync.

      The SETUP_CODE secret of your Worker. The app then makes a sync code for your other devices.

      This server has a sync code already.

      Choose "I have a code" and enter the code of your other device. Or make a new code: your other devices then stop to sync until you enter the new code on them.

      Sync code

      Keep the code secret, for example in your password manager. To add a device, open the link on it, or enter the server address and the code.
